# Vibe Quest

Vibe Quest is a mobile social adventure web application that turns everyday life into real-world quests, skill building, and local partner rewards.

## Project Overview

- **Core Application**: Built with TanStack Start, React 19, TypeScript, and Tailwind CSS v4.
- **Features**: Interactive quest exploration, skill matching, XP system, and partner ecosystem concepts.


## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
